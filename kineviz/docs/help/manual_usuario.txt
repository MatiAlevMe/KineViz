# Manual de Usuario KineViz

## Introducción
KineViz es una aplicación diseñada para la gestión y análisis de estudios kinesiológicos. Permite cargar archivos de estudio en formato CSV o TXT, crear estudios, gestionar archivos y exportar resultados en formato TXT o PDF.

## Indicaciones Para el Formulario para Crear/Editar Estudio(s)
1.  **Nombre del Estudio**: Ingrese un nombre único para el estudio (mínimo 3 caracteres).
2.  **Cantidad de Participantes**: Especifique la cantidad de participantes de prueba (ej: 4). Debe ser un número entero positivo.
3.  **Cantidad de Intento(s) de Prueba**: Especifique la cantidad de intentos por prueba (ej: 1). Debe ser un número entero positivo.
4.  **Variable(s) Independientes (VIs) y Sub-valores**:
    *   Utilice el botón "+ Añadir Variable Independiente" para definir una nueva VI.
    *   Para cada VI, use el botón `+` para añadir sus sub-valores (valores específicos, ej: para una VI "TipoSalto", los sub-valores podrían ser "CMJ", "SJ").
    *   **¿Multiple?**: Marque esta casilla si para esta VI un mismo participante puede tener archivos con diferentes sub-valores de esta VI (ej: Pte01 CMJ ... y Pte01 SJ ...). Si no se marca, un participante solo puede tener un sub-valor de esta VI asignado a través de todos sus archivos (ej: si Pte01 tiene un archivo con "PesoObeso", todos los demás archivos de Pte01 deben usar "PesoObeso" para esa VI, o "Nulo" si aplica).
    *   **¿Obligatorio?**: Esta casilla solo aparece si marca "¿Multiple?". Si la marca, significa que cada participante del estudio DEBE tener al menos un archivo para CADA sub-valor definido en esta VI. Si no se marca (pero "¿Multiple?" sí), los participantes pueden tener algunos o todos los sub-valores de esta VI.
    *   Puede añadir tantas VIs y sub-valores como necesite. Cada VI debe tener al menos dos sub-valores.
    *   Utilice el botón "🗑️" para eliminar un sub-valor que no necesite.
    *   Los sub-valores no pueden estar vacíos y no pueden repetirse exactamente (sensible a mayúsculas/minúsculas). Ej: "CMJ" y "cmj" son válidos, pero "CMJ" y "CMJ" no.
    *   Estos sub-valores se usarán (en futuras versiones) para validar los nombres de los archivos que cargue.
5.  **Guardar**: Haga clic en el botón "Guardar" para guardar el estudio. Si hay errores de validación (nombre duplicado, campos inválidos, sub-valores duplicados), se mostrará un mensaje.

## Ventana Principal: Lista de Estudio(s)
Muestra una lista de todos los estudios cargados al sistema.
1. Ver: Haga clic en el botón "Ver" para ver los archivos asociados con un estudio.
2. Editar: Haga clic en el botón "Editar" para modificar los detalles del estudio.
3. Eliminar: Haga clic en el botón "Eliminar" para eliminar un estudio.

## Ventana: Vista del Estudio (Lista de Archivos)
Muestra una lista de todos los archivos del Estudio específico.
1.  **Agregar Archivos**: Haga clic en el botón "Agregar Archivos" para agregar archivos al estudio.
2.  **Formato de Archivo**: Los nombres de archivo deben seguir un formato consistente: `ID_Participante [SubValorVI1] [SubValorVI2] ... Intento.txt` (o .csv).
    *   `ID_Participante`: Debe comenzar con una o más letras seguidas de uno o más números (ej: `P01`, `Sujeto007`, `Participante1`). No debe contener espacios.
    *   `[SubValorVI...]`: Son los sub-valores de las Variables Independientes definidas para el estudio, separados por espacios. Si un sub-valor no aplica, se puede usar la palabra `Nulo`.
    *   `Intento`: Un número que indica el intento de la prueba.
    *   Ejemplo: `P01 CMJ PRE 1.txt`, `Sujeto02 SJ Nulo 3.csv`.
3.  **Eliminar Archivos**: Haga clic en el botón "Eliminar" junto a un archivo para eliminarlo del estudio.
4.  **Ver Archivos**: Haga clic en el botón "Ver" para abrir el archivo con la aplicación predeterminada del sistema.
5. Abrir Carpeta de Estudio: Abre la carpeta que contiene el Estudio seleccionado.
6. Exportar: Haga clic en el botón "Exportar" para entrar a la ventana de Exportar.

## Ventana: Exporta Archivos
1. Archivos: Exportar los datos del estudio en formato TXT con los parametros seleccionados.
2. Gráficos: Para la exportación en PDF, seleccione los parametros que desea incluir para la comparación de la gráfica.
3. Lista de Archivos Exportados: Se muestra una lista con los archivos exportados, los cuales se pueden ver o eliminar.
