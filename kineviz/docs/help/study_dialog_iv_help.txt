Guía Rápida: Variables Independientes y Descriptores

**¿Qué son?**

* **Variable Independiente (VI):** Una categoría o factor que quieres estudiar (ej: "Tipo de Salto", "Condición del Sujeto").
* **Descriptor:** Un valor específico dentro de una Variable Independiente (ej: para "Tipo de Salto", los descriptores podrían ser "CMJ", "SJ", "DropJump").

**¿Cómo usarlos?**

1. **Añadir VI:** Haz clic en "+ Añadir Variable Independiente" para crear una nueva categoría. Dale un nombre claro.
2. **Añadir Descriptores:** Haz clic en el icono `+` junto al nombre de la VI para añadir los posibles valores (descriptores) para esa variable.
    * Cada VI debe tener **al menos dos** descriptores.
    * Los nombres de VI y Descriptores no pueden estar vacíos ni repetidos dentro del mismo estudio.
3. **Eliminar:** Usa el icono `🗑️` para eliminar una VI completa o un descriptor específico.
4. **Orden:** El orden en que defines las VIs es **importante**. Determina cómo debes nombrar tus archivos de datos.

**Nombrar Archivos:**

El formato debe ser: `PteXX [Desc_VI1] [Desc_VI2] ... [Desc_VIn] NN_Frecuencia.ext`

* `PteXX`: Identificador del paciente.
* `[Desc_VI1]`: Un descriptor válido de la **primera** VI definida.
* `[Desc_VI2]`: Un descriptor válido de la **segunda** VI definida.
* ... y así sucesivamente para todas las VIs definidas.
* `NN`: Número del intento.
* `_Frecuencia.ext`: Sufijo añadido durante el procesamiento (ej: `_Cinematica.txt`).

**Valor "Nulo":**

* Si un archivo no corresponde a un descriptor específico para una VI en particular, puedes usar la palabra `Nulo` (exactamente así, con 'N' mayúscula) en esa posición en el nombre del archivo.
* **Regla:** El nombre del archivo debe tener **todas** las posiciones de VI representadas (ya sea con un descriptor válido o con `Nulo`), y **al menos una** posición debe tener un descriptor válido (no puede ser todo `Nulo`).

**Ejemplo (VIs: "Tipo Salto", "Condición"):**

* `Pte01 CMJ Obeso 01_Cinematica.txt` (Válido)
* `Pte02 SJ Nulo 03_Cinematica.txt` (Válido - Sin condición específica)
* `Pte03 Nulo Normal 01_Cinematica.txt` (Válido - Sin tipo de salto específico)
* `Pte04 CMJ 02_Cinematica.txt` (INVÁLIDO - Falta posición para "Condición")
* `Pte05 Nulo Nulo 01_Cinematica.txt` (INVÁLIDO - Debe tener al menos un descriptor no-Nulo)

**Edición:**

* Al editar un estudio, **no puedes** añadir ni eliminar VIs o Descriptores.
* **Sí puedes** cambiar el nombre de las Variables Independientes.
