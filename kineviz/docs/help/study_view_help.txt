Guía Rápida: Vista del Estudio

Esta vista te permite gestionar los archivos y análisis de un estudio específico.

**Botones Principales:**

* **<< Volver a Estudios:** Regresa a la lista de todos tus estudios.
* **Agregar Archivos:** Abre un diálogo para seleccionar archivos `.txt` o `.csv` y añadirlos a este estudio.
    * Los nombres de archivo deben seguir el formato definido por las Variable(s) Independientes (VIs) del estudio.
    * **Validación:** Al agregar, el sistema verificará que no se exceda la **Cantidad de Participantes** ni la **Cantidad de Intento(s) de Prueba por participante** definidos para este estudio, considerando tanto los archivos existentes como los nuevos. También se aplicarán las reglas de combinación y obligatoriedad de sub-valores definidas para cada VI.
* **Abrir Carpeta Estudio:** Abre la carpeta en tu sistema donde se almacenan los archivos procesados y originales de este estudio.
* **Gestionar Alias Sub-valores:** Asigna nombres más legibles (alias) a los sub-valores definidos para este estudio (ej: "CMJ" -> "Salto Contra Movimiento"). Estos alias se usan en gráficos y reportes y son **específicos para este estudio**.
* **Análisis Discreto:** Abre la vista para generar y gestionar análisis estadísticos comparativos entre grupos definidos por los sub-valores.
* **Botón `?` (Verde, arriba a la derecha):** Muestra esta guía de ayuda.

**Detalles del Estudio:**

* Muestra información básica: Nombre del Estudio, Cantidad de Participantes, Cantidad de Intento(s) de Prueba.
* **Variable(s) Independientes (VIs):** Lista los nombres de las categorías definidas (ej: "Tipo Salto, Condición").
* **Botón `ℹ️` (Junto a VIs):** Muestra un popup con los sub-valores específicos definidos para cada VI (usando los alias asignados) y cómo se manejan sus sub-valores (ej: "Múltiple y Obligatorio", "No Múltiple").
* **Alias Asignados:** Muestra todos los sub-valores definidos para el estudio y sus alias correspondientes.

**Navegador de Archivos:**

* Muestra una lista de los archivos asociados a este estudio.
* **Columnas:**
    * `Participante`: Identificador del participante extraído del nombre del archivo.
    * `Nombre Archivo`: Nombre completo del archivo.
    * `Tipo`: "Procesado" (generado por Kineviz) u "Original" (copia del archivo fuente).
    * `TipoDeDato`: Tipo de datos procesados (Cinematica, Cinetica, etc.) o "N/A" para originales.
* **Búsqueda:** Escribe parte del nombre del archivo o participante y presiona Enter para filtrar.
* **Filtros (Tipo, Tipo de Dato):** Selecciona valores en los menús desplegables para filtrar. Haz clic en "Limpiar Filtros" para volver a ver todos.
* **Paginación:** Usa los botones `<<`, `<`, `>` `>>` o introduce un número de página para navegar.
* **Acciones (al seleccionar un archivo):**
    * **Ver Archivo:** Abre el archivo con el programa predeterminado de tu sistema.
    * **Eliminar Archivo:** Borra permanentemente el archivo del estudio. ¡No se puede deshacer!

**Formato de Nombres de Archivo:**

* `ID_Participante [Desc_VI1] [Desc_VI2] ... NN_TipoDeDato.ext`
    * `ID_Participante`: Debe comenzar con una o más letras seguidas de uno o más números (ej: `P01`, `Sujeto007`, `Participante1`). No debe contener espacios.
    * `[Desc_VI1]`, `[Desc_VI2]`, ...: Sub-valores de las VIs definidas, en orden.
    * `NN`: Número de intento.
    * `_TipoDeDato.ext`: Sufijo y extensión.
* Usa `Nulo` si un sub-valor no aplica para una VI en ese archivo.
* Debe haber **al menos un** sub-valor que **no** sea `Nulo`.
* El **orden** de los sub-valores debe coincidir con el orden de las VIs definidas en el estudio.
* Consulta la ayuda `(?)` en la ventana de Crear/Editar Estudio para más detalles sobre VIs y sub-valores.
